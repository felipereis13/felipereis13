## Sobre mim

Sou um **Desenvolvedor Backend e FullStack em formação**, apaixonado por tecnologia, construção de soluções e evolução contínua. Atualmente, curso **Análise e Desenvolvimento de Sistemas pelo SENAC** e também sou formado em **Ciências Contábeis**, o que amplia minha visão estratégica para atuar em sistemas corporativos, financeiros e ERPs.

Tenho experiência prática em projetos reais entregues para clientes e parceiros como **Cesar School** e **Mesa Tech**, além de participação em projeto com destaque no **Porto Digital**. Meu foco principal está no desenvolvimento de aplicações robustas, organizadas e voltadas para resolver problemas reais de negócio.

Atualmente, busco uma **oportunidade de estágio em Desenvolvimento de Software**, onde eu possa aplicar meus conhecimentos, crescer tecnicamente e contribuir com times de tecnologia.

## Projetos em destaque

### Neuro — Gerenciador de Atendimentos
Sistema web desenvolvido para psicopedagogos organizarem **atendimentos, agendamentos, relatórios e documentos por paciente**, substituindo controles manuais em planilhas e cadernos.

**Tecnologias:** React, HTML, CSS e Bootstrap

### ANU — Gestão de Colaboradores
Plataforma voltada para a gestão de equipes em empresas com múltiplos projetos simultâneos. O sistema permite **monitoramento de carga horária, controle de ausências e alertas automáticos**, apoiando a identificação de riscos operacionais.

**Tecnologias:** Node.js, MongoDB, React, TypeScript e Mantine UI
